# TaskFlow

A modern project and task management platform
built for small teams and freelancers.

## Overview

TaskFlow is a web-based application that helps
small teams organize projects, assign tasks,
track progress, and manage deadlines in one place.

## Project Status

🚧 In Development

## Planned Features

- User authentication
- Project creation and management
- Team member management
- Task assignment and tracking
- Kanban board
- Task priorities and deadlines
- Dashboard with project statistics
- Responsive user interface

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
